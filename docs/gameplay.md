# Gameplay документация

## Физические параметры

### Гравитация

- Глобальная гравитация: `Physics 2D` → `Gravity Y` = `-9.81`.
- У игрока `CharacterPlatformer` в `Rigidbody 2D` стоит `Gravity Scale = 0`, поэтому на него глобальная гравитация не действует — падение и прыжок полностью контролируются скриптом `PlayerCharacter` через параметры `Jump_gravity` и `Jump_fall_gravity`.
- На стены и декор гравитация также не действует, потому что у них нет `Rigidbody 2D` — они статические.

### Массы объектов

- `CharacterPlatformer` → `Rigidbody 2D` → `Mass` = `10`.
- Остальные объекты сцены (`стены`, `декор`) не имеют `Rigidbody 2D`, поэтому их масса не учитывается физикой — они статичны.

### Физические материалы

- `Physics Material 2D` в проекте отсутствуют: у всех коллайдеров (`CapsuleCollider 2D` у игрока, коллайдеры стен) стоит `None (Physics Material 2D)`.
- Это значит, что трение и упругость берутся по умолчанию (Friction = 0.4, Bounciness = 0), отдельных материалов для скольжения или отскока нет.

### Коллайдеры

- Игрок: `CapsuleCollider 2D` — используется для столкновения со стенами и землёй.
- Стены: `BoxCollider 2D` (или аналогичный) — статические, без `Rigidbody 2D`.
- Префабы `TreeBackground`, `Grass`, `Lever` коллайдеров не имеют (кроме `Lever`, у которого, судя по скрипту `Lever`, коллайдер есть — но сам рычаг на сцену не выставлен).

## Префабы

| Префаб | Роль | Компоненты | Опасность / польза |
|---|---|---|---|
| `CharacterPlatformer` | Игрок | `SpriteRenderer`, `Animator`, `Rigidbody 2D`, `CapsuleCollider 2D`, скрипты `PlayerCharacter`, `CharacterAnim`, `CharacterHoldItem` | Управляется игроком |
| `TreeBackground` | Декор | `SpriteRenderer` | Не влияет на геймплей, часть параллакс-фона |
| `Grass` | Декор | `SpriteRenderer` | Не влияет на геймплей |
| `Lever` | Интерактивный объект | `SpriteRenderer`, коллайдер, скрипт `Lever` | На сцене отсутствует, но потенциально переключает что-то в уровне |

**Опасные / полезные элементы:**

- В проекте нет врагов и бонусов в явном виде — префабов с уроном или подбором нет.
- Единственные объекты с коллизией — стены (не префабы) и сам игрок.
- `Lever` в связке с `CarryItem` / `CharacterHoldItem` образует механику подбора предметов, но на текущей сцене не задействован.

## UI

UI в проекте отсутствует. Объект `Canvas` на сцене не найден, элементы интерфейса (`Text`, `Image`, `Button`) не используются.

## Параметры, влияющие на сложность и поведение игры

### Rigidbody 2D 

| Параметр | Значение | Что делает |
|---|---|---|
| `Body Type` | `Dynamic` | Объект полностью подчиняется физике Unity. |
| `Material` | `None (Physics Material 2D)` | Трение и упругость по умолчанию. |
| `Simulated` | True | Физика для объекта включена. |
| `Use Auto Mass` | False | Масса задаётся вручную, а не из коллайдера. |
| `Mass` | `10` | Масса игрока. Влияет на столкновения с другими телами (в текущей сцене других динамических тел нет). |
| `Linear Drag` | `1` | Сопротивление линейному движению. Чем выше — тем быстрее игрок тормозит. |
| `Angular Drag` | `1` | Сопротивление вращению. |
| `Gravity Scale` | `0` | Гравитация на игрока не действует. Именно поэтому падение реализовано вручную через скрипт (`Jump_gravity`, `Jump_fall_gravity`). |
| `Collision Detection` | `Discrete` | Обычная точность обнаружения столкновений. При высоких скоростях возможны «проскоки» сквозь стены — можно переключить на `Continuous`. |
| `Sleeping Mode` | `Start Awake` | Объект не «засыпает» при остановке. |
| `Interpolate` | `Interpolate` | Сглаживает движение между кадрами физики — картинка выглядит плавнее. |
| `Constraints` | не заданы | Нет запретов на движение/вращение по осям. |

### Скрипт PlayerCharacter (параметры Inspector)

Скрипт `PlayerCharacter` — основной источник настроек сложности и поведения игрока.

| Параметр | Назначение |
|---|---|
| `Player_id` | Идентификатор игрока (для мультиплеера / сохранений). |
| `Max_hp` | Максимальное здоровье. |
| `Invulnerable` | Неуязвимость (отладочный флаг). |
| `Move_accel` | Ускорение при начале движения. |
| `Move_deccel` | Замедление при остановке. |
| `Move_max` | Максимальная скорость передвижения. |
| `Can_jump` | Разрешён ли прыжок. |
| `Double_jump` | Двойной прыжок. |
| `Jump_strength` | Сила прыжка. |
| `Jump_time_min` | Минимальное время удержания прыжка. |
| `Jump_time_max` | Максимальное время удержания прыжка. |
| `Jump_gravity` | Гравитация во время прыжка вверх. |
| `Jump_fall_gravity` | Гравитация во время падения. |
| `Jump_move_percent` | Насколько можно двигаться в воздухе. |
| `Ground_layer` | Слой, который считается «землёй». |
| `Ground_raycast_dist` | Дистанция проверки земли под ногами. |
| `Can_crouch` | Разрешено ли приседать. |
| `Crouch_coll_percent` | Во сколько раз сжимается коллайдер при приседании. |
| `Reset_when_fall` | Телепорт на старт при падении. |
| `Fall_pos_y` | Y-координата, ниже которой игрок считается упавшим. |
| `Fall_damage_percent` | Процент урона при падении. |

### Что менять для усложнения / упрощения

- `PlayerCharacter` → `Move_max`, `Move_accel`, `Move_deccel` — скорость и «отзывчивость» управления.
- `PlayerCharacter` → `Jump_strength`, `Jump_gravity`, `Jump_fall_gravity` — высота и «вес» прыжка.
- `PlayerCharacter` → `Max_hp`, `Fall_damage_percent` — выживаемость.
- `PlayerCharacter` → `Ground_raycast_dist`, `Ground_layer` — точность определения земли (при ошибке игрок «застревает» или прыгает бесконечно).
- `Rigidbody 2D` → `Mass`, `Linear Drag`, `Angular Drag` — инерция и торможение.
- `Rigidbody 2D` → `Collision Detection` → `Continuous` — если на уровне будут быстрые объекты.
- `Camera` (скрипт `FollowCamera`) → размер / скорость слежения — обзор и ощущение скорости.
- `Physics 2D` → `Gravity Y` — глобально, но на игрока не влияет из-за `Gravity Scale = 0`; влияет только на объекты с ненулевым `Gravity Scale`.

| `CharacterAnim` | Переключение анимаций персонажа. |
| `CharacterHoldItem` | Удержание подобранного предмета в руке. |
| `CarryItem` | Логика предмета, который можно подобрать. |
| `Lever` | Логика рычага. |
| `FollowCamera` | Слежение камеры за игроком. |
| `ParallaxBackground` | Параллакс-движение фона. |
| `TheAudio` | Управление аудио. |
