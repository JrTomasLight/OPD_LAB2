# Изменения

## Изменения Джуниора
- Перестройка уровня -> для большей сложности прохождения (уровень стал больше, препятствия усложнились)
- Изменены параметры Jump_strength, Jump_gravity, Jump_fall_gravity (CharacterPlatformer) -> для большей сложности прохождения (более быстрое падение)
- Изменен параметр Level_right (Main Camera) -> для увеличение границы уровня
- Изменены параметры Move_accel, Move_deccel, Move_max (CharacterPlatformer) -> для большей сложности (персонаж двигается быстрее, останавливается не сразу)
