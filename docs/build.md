# Built.md

Проект создан на основе шаблона **Simple 2D Template** из Unity Asset Store.

Источник шаблона:

<https://assetstore.unity.com/packages/templates/packs/simple-2d-template-137981>

Тип проекта: 2D-платформер.

## Built settings

Используемая версия Unity: 2020.1.18f1
Поддерживаемые платформы: PC, Mac, Linux Standalone

Параметры внутри проекта
Fixed TimeStep: 0.02
Maximum AllowedTimeStep 0.3333333

Users Layers: User Layer 8: Platforms

## Packages download from Package manager
В игре они отсутсвуют

По указанию автора с источника шаблона в игре использованы пакеты The Last Crystal https://thelastcrystal.com/
